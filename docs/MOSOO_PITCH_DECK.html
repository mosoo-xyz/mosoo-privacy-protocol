01 / The Problem & Abey Opportunity

AbeyChain has developed elite multi-layered transaction throughput. However, like all public EVM chains, transaction data is completely transparent.

Current Challenge

  • Financial Surveillance: Every wallet balance, transfer, and DeFi action is publicly visible to competitors and exploiters.
  • Institutional Hesitation: Enterprises and payroll operators cannot deploy on AbeyChain due to lack of confidential accounting.
  • MEV Exploitation: Front-running bots extract value from large public transactions on DEXs and liquidity pools.

The Mosoo Solution

  • Cryptographic Cloak: Zero-Knowledge SNARK proofs break the link between sender, recipient, and transaction value.
  • Institutional Liquidity: Attracts privacy-minded capital and high-net-worth volume directly into AbeyChain.
  • Ecosystem Synergy: Built for deep composability with Abey AMMs, token standards, and inter-app architecture.

02 / Core Technical Architecture

Mosoo utilizes modern, hardened zero-knowledge cryptographic primitives engineered for high performance on AbeyChain.

Hash Engine
Poseidon-BN254

Circuit-optimized algebraic hashing operating over the BN254 scalar field for minimal gas and proving time.

Merkle Tree
Depth 20 Tree

Supports up to 1,048,576 shielded notes with a 64-slot ring buffer cache for concurrent historical Merkle roots.

Privacy Model
JoinSplit 2-to-2

UTXO-based note joining and splitting with automatic change note generation and on-chain ECDH encrypted memos.
