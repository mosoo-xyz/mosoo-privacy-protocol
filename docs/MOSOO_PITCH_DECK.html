01 / Ecosystem Motivation

The Privacy Dilemma on Public Blockchains

AbeyChain delivers high-throughput Layer-1 execution, but public transparency restricts institutions, enterprises, and high-volume traders.

02 / Technical Architecture

Hardened Zero-Knowledge Cryptographic Core

Engineered with circuit-optimized primitives designed for minimal gas cost and high verification throughput on EVM.

Poseidon-BN254

Algebraic hash circuit operating over the BN254 scalar field for instantaneous client proving and minimal on-chain gas.

Depth-20 Merkle Tree

Supports over 1,048,576 shielded notes with a 64-slot ring buffer cache for historical roots to prevent mempool concurrency race conditions.

JoinSplit 2-to-2 Multi-UTXO

Enables arbitrary-amount payments by merging 2 input notes and splitting into recipient payment + confidential change notes.

End-to-End ECDH Encrypted Memos (Calldata Delivery)

Senders encrypt recipient note metadata using the recipient’s public viewing key via ECDH (secp256k1). Recipients scan on-chain event logs with their secret viewing key to reconstruct balances without relying on centralized indexing servers.
